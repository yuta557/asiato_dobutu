# あしあとどうぶつ

なぞると足あと、タップすると手形。なぞった形やタップの回数で、うまれるどうぶつが変わります。
うまれたどうぶつは草原であそびはじめます。

「まちであそぶ、をつくる（Playable City 入門ワークショップ）」の体験版ボード
Color Shift Walk の、新しいバージョンです。

## あそびかた

| なぞる形（足あと） | どうぶつ | タップなど（手形） | どうぶつ |
|---|---|---|---|
| まっすぐ | ヒヨコ | 1回タップ | ウマ |
| ギザギザ | ウサギ | 2回タップ | シマウマ |
| まる | クマ | 3回タップ | トラ |
| さんかく | ネコ | 4回タップ | キリン |
| しかく | ゾウ | 5回タップ | きょうりゅう |
| ぐるぐる | コアラ | ながおし | フラミンゴ |

- 足あとは、色が変わって寄りあつまり、大きな足あとになります。かかとが顔、指先があしです。
- 手形は、指があしやはね・トゲに、親指が首や顔になります。
- 長くなぞるほど、大きなどうぶつになります。
- どうぶつをタップすると、それぞれの声であいさつします。

## どうぶつのあそび

さそう子が「〇〇、しよう！」と言い、なかまがこたえてから始まります。
あそんでいる子をタップすると、そのあそびの中だけの反応をします（ときどき、あそびが少しじゃまされます）。

- ふたりから：おいかけっこ／ボールあそび（3〜4ひきでも回せます）／かくれんぼ／ダンス／みずあび／ぎょうれつ
- 4ひき以上そろうと：だるまさんがころんだ／よーいどん／つなひき

あそびは同時に1つだけです。入っていない子は、あそびを見まもっておうえんします。

## すれちがったときのおしゃべり

あそんでいない子どうしが近づくと、立ちどまってひとこと ふたこと話します。
「あ、こんにちは〜」「どこ いくの〜？」のほか、ネコとトラ、ウマとシマウマなど、
その組み合わせだけのかけあいもあります。
10回に1回くらいは「ひま〜」「あそぶ？」の話から、そのままあそびがはじまります。

## ファイル

```
index.html            ページ本体（HTML・CSS）
ad/prints.js          足あと・手形の形と、スタンプの質感
ad/species-foot.js    足あとのどうぶつ6種
ad/species-hand.js    手形のどうぶつ6種
ad/gesture.js         なぞった形の判定
ad/scene.js           草原（空・丘・花・池・しげみ・雲）
ad/play.js            どうぶつの動き・ことば・描画
ad/acts.js            ふたりからのあそび、あそびの選び方
ad/acts-group.js      4ひき以上のあそび
ad/chat.js            すれちがったときのおしゃべり
ad/debug.js           重さの計測パネル
ad/main.js            入力・足あと・自動デモ・図鑑・ループ
```

外から読みこむのは Google Fonts だけです（Zen Maru Gothic / Zen Kaku Gothic New / Yomogi / IBM Plex Mono）。
ビルドは不要で、このまま公開できます。

## 見かた

- ファイルをそのままブラウザで開く（`index.html`）
- GitHub Pages：Settings → Pages → Branch を `main` / `root` にする

## 重さの計測

ボード上の「まちであそぶボード」の文字を3回つづけてタップすると、計測パネルが出ます。
URL の末尾に `?debug` をつけても出ます。

- 描くこまかさは自動で調整します（重いときは下げ、なめらかなら もどします）。
- 背景は別のキャンバスに一度だけ描き、毎フレーム描きなおしません。

## つくりかた・調整

- どの形・回数でどのどうぶつが出るか：`ad/main.js` の `BY_SHAPE` / `BY_TAPS`
- あそびの選ばれやすさ：`ad/acts.js` の `X.schedule`
- どうぶつの数：`ad/play.js` の `P.setCapacity`（草原の広さから決めます）
